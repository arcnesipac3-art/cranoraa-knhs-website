## 1. Logging In

> **Go to:** Portal website → Login

1. Enter your **email**.
2. Enter your **password**.
3. Select **Faculty**.
4. Click **Log In**.

---

## 2. Dashboard

> **Go to:** Sidebar → Dashboard

Your home page. Shows:

- **Quick actions** — My Classes, Post Announcement, Schedule, Messages
- **Overview stats** — today's attendance, pending grades, total students
- **My Classes** — your assigned classrooms with attendance status
- **Today at a glance** — schedule, announcements, recent messages
- **Pending Tasks** — urgent items (unmarked attendance, missing grades)

**Tip:** Check daily for what needs attention.

## 3. My Classes

> **Go to:** Sidebar → My Classes

### Open a Class

1. Click **My Classes**.
2. Click a class card.

### Tabs Inside a Class

| Tab | What's There | How to Use |
|---|---|---|
| **Stream** | Class announcements | Post, edit, delete announcements |
| **Materials** | Learning resources | Upload DLPs, modules, worksheets |
| **Grades** | Student grades | Input and view grades |
| **Attendance** | Daily attendance | Mark students present/absent/late/excused |
| **People** | Enrolled students | View student list |

### Post an Announcement

1. Open a class → **Stream** tab.
2. Click **New Post**.
3. Enter title and content.
4. Attach files (optional).
5. Click **Post**.

### Upload Materials

1. Open a class → **Materials** tab.
2. Click **Upload**.
3. Enter title, description, type (DLP/Module/Handout).
4. Select quarter and week.
5. Attach the file.
6. Click **Upload**.

## 5. Marking Attendance

> **Go to:** Sidebar → My Classes → Attendance tab

### Steps

1. Go to **My Classes** → select a class.
2. Click the **Attendance** tab.
3. Select the **date** (defaults to today).
4. Mark each student:
   - **P** = Present
   - **A** = Absent
   - **L** = Late
   - **E** = Excused
5. Add remarks (optional).
6. Click **Save**.

**Tip:** Use keyboard shortcuts (P/A/L/E) for fast marking.

### View History

1. Open a class → **Attendance History** tab.
2. Use the date filter to find records.

## 6. Attendance Dashboard (SF2)

> **Go to:** Sidebar → Attendance Dashboard

Official DepEd attendance report.

### Steps

1. Go to **Attendance Dashboard**.
2. Select **Academic Year**, **Month**, **Grade Level**, **Section**.
3. See the attendance matrix — students on rows, days on columns.
4. Click any cell to change status (P/A/L/E).
5. Use keyboard shortcuts for quick editing.

### Export

1. Set filters.
2. Click **Export PDF** or **Export Excel**.
3. Download or print.

## 7. Entering Grades

> **Go to:** Sidebar → Grade Submission

### Steps

1. Go to **Grade Submission**.
2. Find the subject/class you want to grade.
3. Click **Enter Grades**.
4. Enter grades for each student.
5. Click **Save Draft** to save without submitting.
6. Click **Submit Grades** when ready for admin review.

### Statuses

| Status | Meaning |
|---|---|
| **Draft** | Not submitted — you can edit |
| **Submitted** | Waiting for admin review |
| **Approved** | Grades are final |
| **Locked** | Period closed — request reopening if needed |

### Request Reopening

1. Find the locked submission.
2. Click **Request Reopening**.
3. Enter a reason.
4. Submit.

## 10. Chat

> **Go to:** Sidebar → Communication Center

### Send a Message

1. Click **+** or **New Chat**.

## 11. Compliance

> **Go to:** Sidebar → My Compliance

Submit required reports (weekly/monthly/quarterly/yearly).

### Submit a Document

1. Go to **My Compliance**.
2. Find the item that needs submission.
3. Click **Submit** or **Resubmit**.
4. Upload files (max 10 files, 50MB each).
5. Click **Submit for Review**.

### Statuses

- **Not Submitted** — you need to submit
- **Pending Review** — waiting for admin
- **Approved** — accepted
- **Rejected** — check remarks, resubmit

## 12. Enrollment

> **Go to:** Sidebar → Enrollment

### Review Applications

1. Go to **Enrollment** → **Applications** tab.
2. Filter by status if needed.
3. Click an application to open it.
4. Review info and documents.
5. Take action:
   - **Start Review** — begin reviewing
   - **Approve** — approve application
   - **Reject** — deny (provide reason)
   - **Request Requirements** — ask for more docs
   - **Enroll** — create student account, assign to section

## 16. FAQ

**Can't log in?**
- Check email and password
- Caps Lock off?
- Locked out? Wait 15 minutes
- Contact admin

**Can't submit grades?**
- Enter grades for all students
- Check if grading period is open
- If locked, request reopening

**Attendance won't save?**
- Check internet connection
- Refresh the page
- Contact IT

**Don't see your classes?**
- Contact admin to check assignments
- Make sure you're logged in as Faculty

**How to generate forms?**
- School Forms → select form → set filters → Export
