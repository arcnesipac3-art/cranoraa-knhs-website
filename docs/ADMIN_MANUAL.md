## 1. Logging In

> **Go to:** Portal website → Login

1. Enter your **email**.
2. Enter your **password**.
3. Select **Admin**.
4. Click **Log In**.

---

## 2. Admin Hub

> **Go to:** Sidebar → System Admin

Your main control center with 6 tabs:

| Tab | What It Does |
|---|---|
| **Overview** | School stats, alerts, quick actions |
| **Audit Logs** | View all system activity |
| **Backups** | Database backup and restore |
| **Website Editor** | Edit public website content |
| **Moderation** | Review reported content |
| **System Health** | Monitor server status |

### Overview Tab

Shows:
- **Stat cards** — students, faculty, classrooms, pending approvals
- **Academic performance** — average grade, attendance rate, passing rate
- **Today's attendance** — daily stats with 7-day trend
- **Recent activity** — latest events
- **System status** — database, API, storage

## 3. Academic Setup

> **Go to:** Sidebar → Academic Setup

9-step wizard for setting up a new school year.

### Steps

| Step | What to Do |
|---|---|
| **1. Academic Year** | Enter year (e.g., 2026–2027), set start/end dates |
| **2. Education Level** | Select JHS, SHS, or Both |
| **3. Academic Periods** | Configure quarters (use Quick Setup for default) |
| **4. Sections** | Create sections, assign advisers, set capacity |
| **5. Subjects** | Create subjects with code, name, grade level |
| **6. Assign Subjects** | Link subjects to sections, assign teachers |
| **7. Review** | Check everything |
| **8. Publish** | Activate the school year |
| **9. Done** | Confirmation |

**Tip:** Complete all steps before publishing.

## 4. Classes

> **Go to:** Sidebar → Classes

### Create a Section

1. Click **+ New Section**.
2. Enter name (e.g., "Grade 7 - Rose").
3. Select grade level.
4. Assign adviser.
5. Set capacity.
6. Click **Save**.

### Edit a Section

1. Click the **pencil icon** on a section.
2. Update info.
3. Click **Save**.

### Delete a Section

1. Click the **trash icon**.
2. Confirm.

**Tip:** Use filters to find sections by grade level.

## 5. Subjects

> **Go to:** Sidebar → Subjects

### Subjects Tab

#### Create a Subject

1. Click **+ New Subject**.
2. Enter code (e.g., "MATH7"), name, grade level.
3. Click **Save**.

#### Edit/Delete

- Click **pencil** to edit, **trash** to delete.

### Assignments Tab

#### Assign Subject to Section

1. Click **+ Assign**.
2. Select section, subject, teacher.
3. Click **Save**.

#### Edit/Remove

- Click **pencil** to edit, **trash** to remove.

## 6. People

> **Go to:** Sidebar → People

Three tabs: Teachers, Students, Parents.

### Teachers Tab

#### Create Teacher

1. Click **+ New Teacher**.
2. Enter email, first name, last name.
3. Select staff title.
4. Click **Create**.
5. Give them the temp password.

#### Reset Password

1. Click **three-dot menu** → **Reset Password**.
2. Give them the new password.

### Students Tab

#### Create Student

1. Click **+ New Student**.
2. Enter LRN (12 digits), first name, last name.
3. Select grade level.
4. Click **Create**.
5. Give them the temp password.

#### Assign to Section

1. Click **three-dot menu** → **Assign Section**.
2. Select section.
3. Click **Confirm**.

### Parents Tab

#### Create Parent

1. Click **+ New Parent**.
2. Enter email, first name, last name.
3. Click **Create**.
4. Give them the temp password.

#### Link to Student

1. Click **three-dot menu** → **Link to Student**.
2. Search and select student.
3. Click **Confirm**.

### Export

- Click **Export** on any tab for Excel/PDF.

## 7. Enrollment

> **Go to:** Sidebar → Enrollment

### Applications Tab

#### Review Application

1. Click an application to open it.
2. Review info and documents.
3. Take action:
   - **Start Review** — begin reviewing
   - **Approve** — approve
   - **Reject** — deny (provide reason)
   - **Request Requirements** — ask for more docs
   - **Enroll** — create student account, assign section

#### Bulk Actions

1. Select multiple applications with checkboxes.
2. Click **Bulk Approve** or **Bulk Reject**.

### Enroll Students Tab

#### Manually Enroll

1. Select a section.
2. Click **Add Students**.
3. Search and select students.
4. Click **Confirm**.

#### Withdraw Student

1. Click **Withdraw**.
2. Select reason.
3. Click **Confirm**.

## 19. Moderation

> **Go to:** Sidebar → System Admin → Moderation tab

Review reported content.

### Review Reports

1. Filter by status (Pending, All).
2. Click a report.
3. Take action:
   - **Dismiss** — no action needed
   - **Delete Message** — remove the message
   - **Suspend User** — suspend the user
   - **Delete Report** — remove the report

## 20. System Health

> **Go to:** Sidebar → System Admin → System Health tab

Monitor server status.

### What You See

- **Gauge cards** — CPU, Memory, Disk, Database usage
- **Service status** — API, Database, Cache, CDN (Operational/Degraded/Down)
- **Uptime** and response time
- **Active sessions**

**Color code:** Green = healthy, Yellow = degraded, Red = down

## 22. FAQ

**Can't log in?**
- Check email and password
- Locked out? Wait 15 minutes

**Teacher can't submit grades?**
- Check grading period is open in Grade Management
- If locked, approve their reopening request

**Enrollment stuck?**
- Check application status
- "Pending Requirements" means applicant needs to upload more docs

**System slow?**
- Check System Health
- If degraded, contact IT

**How to set up new school year?**
- Academic Setup → follow 9 steps

**How to generate forms?**
- School Forms → select form → set filters → Export

**How to view system activity?**
- System Admin → Audit Logs
