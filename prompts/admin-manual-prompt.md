# AI Prompt: Generate KNHS PRISM Portal Admin Manual PDF

## Prompt

```
Generate a comprehensive Admin Manual PDF for the KNHS PRISM Portal (a school management system). The manual must be written in clear, formal English suitable for school administrators and IT staff.

IMPORTANT: Use the EXACT navigation labels and section names below throughout the manual. Do NOT rename, rephrase, or paraphrase any navigation item. Admins will use this manual to navigate the portal, so mismatched names will cause confusion.

---

## PORTAL ACCESS

### Login Steps
1. Go to https://kiwalannhs.vercel.app
2. On the login page, you will see four role cards. Select the card labeled **"Admin"** (subtitle: "Admin Portal").
3. Enter your **Admin Email** in the identifier field.
4. Enter your password.
5. Click **"Sign in to Admin Portal"**.
6. You will be redirected to the **Dashboard**.

### Logging Out
- Click your profile picture or initials in the top-right corner.
- Click **"Log out"**.

## MANUAL STRUCTURE — WRITE EACH CHAPTER AS FOLLOWS

### Chapter 1: Getting Started
- What is the KNHS PRISM Portal?
- System requirements (browser, internet connection)
- How to access the portal (URL, login steps as shown above)
- Understanding the admin dashboard overview

### Chapter 2: Dashboard
- **Dashboard**: Explain the overview cards, enrollment stats, attendance rates, user activity, and alerts. How to interpret the charts and data.
- **Admin Hub**: Central control panel — quick actions for user management, system health, and administrative shortcuts.
- **Analytics**: How to generate reports, filter data by date range, class, subject, or student. How to export data (CSV, PDF).

### Chapter 3: Academics
- **Academic Setup**: Step-by-step guide to configuring the school year, semesters, grading periods, and grading scales. How to set up academic terms.
- **Grade Management**: How to review teacher-submitted grades, approve or reject submissions, view grade summaries per class/section, and generate grade reports.
- **Classes**: How to create new class sections, assign teachers, assign subjects, and manage existing classes.
- **Subjects**: How to create new subjects, assign subject codes, set credit hours, and manage the subject list.

### Chapter 4: Attendance
- **Monitoring**: How to view real-time attendance across all classes, filter by date, class, or student. How to view attendance summaries and trends.
- **Excuse Slips**: How to review excuse slip requests from students across all classes. How to approve or deny requests and add remarks.
- **Audit Trail**: How to view attendance modification logs, who made changes, and when. How to filter and export audit logs.

### Chapter 5: Operations
- **Enrollment**: How to manage student enrollment — approve new enrollments, transfer students, view enrollment statistics, and generate enrollment reports.
- **Schedules**: How to create and manage class schedules, assign time slots, rooms, and teachers. How to resolve scheduling conflicts.
- **Compliance**: How to track staff compliance document submissions, send reminders, and generate compliance reports.
- **Announcements**: How to create, edit, and publish school-wide announcements. How to set announcement priority and visibility.

### Chapter 6: Communication
- **Messages**: How to send messages to individual users, groups, or all staff/students/parents.
- **Notifications**: How to manage notification settings and view notification delivery logs.
- **Calendar**: How to create and manage school events, set event reminders, and mark holidays.

### Chapter 7: People Directory
- **People Directory**: How to search for users by name, role, or section. How to view user profiles, edit user details, activate/deactivate accounts, and grant/revoke admin privileges.

### Chapter 8: System Settings
- **Settings**: System configuration options — general settings, security settings, backup and restore, user role management, and system audit logs. How to create backups and restore from backups.

### Chapter 9: Troubleshooting & FAQ
- Common login issues and solutions
- What to do if a page doesn't load
- Who to contact for technical support
- FAQ section (e.g., "How do I reset a teacher's password?", "How do I recover a deleted class?", "Why can't I see a student's grades?")
```
