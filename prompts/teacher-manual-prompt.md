# AI Prompt: Generate KNHS PRISM Portal Teacher Manual PDF

Use this prompt with an AI tool (ChatGPT, Claude, Gemini) to generate a professional PDF teacher manual for the KNHS PRISM Portal.

---

## Prompt

```
Generate a comprehensive Teacher Manual PDF for the KNHS PRISM Portal (a school management system). The manual must be written in clear, formal English suitable for faculty members with varying technical skill levels.

IMPORTANT: Use the EXACT navigation labels and section names below throughout the manual. Do NOT rename, rephrase, or paraphrase any navigation item. Teachers will use this manual to navigate the portal, so mismatched names will cause confusion.

---

## PORTAL ACCESS

### Login Steps
1. Go to https://kiwalannhs.vercel.app
2. On the login page, you will see four role cards. Select the card labeled **"Faculty"** (subtitle: "Faculty Portal").
3. Enter your **Teacher Email** in the identifier field.
4. Enter your password.
5. Click **"Sign in to Faculty Portal"**.
6. You will be redirected to the **Dashboard**.

### Logging Out
- Click your profile picture or initials in the top-right corner.
- Click **"Log out"**.

## MANUAL STRUCTURE — WRITE EACH CHAPTER AS FOLLOWS

### Chapter 1: Getting Started
- What is the KNHS PRISM Portal?
- System requirements (browser, internet connection)
- How to access the portal (URL, login steps as shown above)
- Understanding the dashboard overview

### Chapter 2: Workspaces
- **Dashboard**: Explain the overview cards, quick stats, recent activity feed, and any shortcut buttons.
- **My Classes**: How to view assigned class sections, class details, and student lists within each section.
- **My Schedule**: How to view your daily and weekly schedule, including subject, time, and room.

### Chapter 3: Teaching
- **Grade Submission**: Step-by-step guide to inputting grades per subject, per grading period. How to save drafts, submit for approval, and view submission status. Include screenshots placeholders.
- **Attendance Dashboard**: How to take attendance (Present, Absent, Late, Excused). How to view attendance summaries and edit past records. Include a note on attendance policies.
- **Excuse Slips**: How to view incoming excuse slip requests from students. How to approve or deny them. How to add remarks.
- **My Compliance**: How to view required compliance documents, upload submitted documents, and track completion status.

### Chapter 4: Communication
- **Messages**: How to compose a new message, reply to messages, and view conversation threads. How to message students, parents, or other teachers.
- **Announcements**: How to view announcements posted by administration or other staff.
- **Notifications**: How to view system notifications (e.g., grade submission reminders, new messages).

### Chapter 5: Directory
- **People Directory**: How to search for teachers, students, or parents by name, role, or section. How to view a person's profile details.

### Chapter 6: Resources
- **Enrollment**: How to view enrolled students in your classes, and any enrollment-related actions.
- **Schedules**: How to view the full school schedule grid.
- **Calendar**: How to view upcoming school events, holidays, and important dates.

### Chapter 7: Account Management
- **Change Password**: Step-by-step to update your password.
- **Settings**: How to update your profile information (name, contact details, etc.).

### Chapter 8: Troubleshooting & FAQ
- Common login issues and solutions
- What to do if a page doesn't load
- Who to contact for technical support
- FAQ section (e.g., "How do I reset my password?", "Why can't I see my classes?")

## FORMATTING REQUIREMENTS

1. Use a professional, formal tone.
2. Each chapter should have a clear title and section headers.
3. Use numbered lists for step-by-step instructions.
4. Use bullet points for feature lists.
5. Include placeholders like [Screenshot: Dashboard Overview] where screenshots should go.
6. Add a Table of Contents at the beginning.
7. Add a footer on each page with "KNHS PRISM Portal — Teacher Manual | Confidential".
8. The manual should be approximately 15–25 pages when rendered as PDF.
9. Use the exact navigation labels from the table above — never paraphrase them.
```
